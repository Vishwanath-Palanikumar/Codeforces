# Codeforces Solutions

A collection of my solutions to [Codeforces](https://codeforces.com/) problems, implemented in **Java** as part of my competitive programming practice.

## 📂 Repository Structure

```text
Codeforces/
├── src/
│   ├── rating800/
│   │   ├── CF1829A_LoveStory.java
│   │   ├── CF1858A_Buttons.java
│   │   └── CF1873A_ShortSort.java
│   └── Main.java
├── .gitignore
└── README.md
```

Solutions are organized by problem rating to make practice, revision, and progress tracking easier.

## 🚀 Running a Solution

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/Codeforces.git
   ```

2. Open the project in IntelliJ IDEA.
3. Select a Java solution under `src/`.
4. Run the file using the installed JDK.

Each solution can be executed independently using its `main` method.
